# Noubissie-kamga-wilfried-20U2671-Jamaa-bank
Jamaa-bank est une plateforme complète de gestion multi-bancaire, conçue autour d'une architecture microservices moderne et scalable. Le projet vise à offrir un écosystème sécurisé et performant permettant aux utilisateur la gestion de leur comptes dans diverses banques à travers une seule interface

Dans ce repository, nous avons 4 branches : 
- la branche actuel (main) : contient juste ce README
- la branche backend : contient le code backend de l'application (Tous les micro services)
- la branche frontend-web : contient le code frontend pour l'interface d'administration (web)
- la branche frontend-mobile : contient le code pour l'application mobile (flutter), destinée aux utilisateurs finaux
