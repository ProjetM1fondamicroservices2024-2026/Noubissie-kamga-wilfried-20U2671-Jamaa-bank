# Noubissie-kamga-wilfried-20U2671-Jamaa-bank
Jamaa-bank est une plateforme complète de gestion multi-bancaire, conçue autour d'une architecture microservices moderne et scalable. Le projet vise à offrir un écosystème sécurisé et performant permettant aux utilisateur la gestion de leur comptes dans diverses banques à travers une seule interface
